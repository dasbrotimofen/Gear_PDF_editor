# Contributing

Keep the repository private during initial development. Submit small changes with a clear description and relevant checks. Contributions are offered under AGPL-3.0-or-later; submit only code and assets you have the right to contribute. Identify external sources and licences.

Keep PDF operations out of the domain model and UI events out of Core. Store geometry in millimetres. Add meaningful checks for persistence, geometry and command history. Pen/touch changes need hardware validation; name the hardware used.
